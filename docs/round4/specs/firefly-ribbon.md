# The ribbon

Carry an open hand slowly through the dark, palm up, and fireflies peel off the nearest cloud and string out behind it — a soft strand of light following every slow curve of the hand. Stop, and the strand gathers and lands on your fingers; move fast and it scatters. It sits exactly between the two rules players already know (still -> they land, fast -> they scatter). Zero draw calls; ~200 lines in `src/world/fireflies.js`.

## State number (shared with 'firefly-escort')
`FOLLOW = 5` (`ESCORT = 4` belongs to the escort). FOLLOW is excluded from the sync pass, LANDED/APPROACH handling, and cleared (`followHand[i] = -1; followIdx[i] = -1`) in the repel loop and every `releaseSlot` path; escort recruiting must skip FOLLOW fireflies.

## Gesture (per hand, in the hand-flag block)
Constants `RIB = { speedMin: 0.05, speedMax: 0.35, breakSpeed: 0.5, normalY: 0.15, pauseGrace: 0.4, lostGrace: 0.4, recruitAfter: 0.5, recruitEvery: 0.3, max: 16 (x particleScale, rounded), sampleStep: 0.02, ring: 256, spacing: 4, lift: 0.09, inbound: 0.3 }`. Per hand: `slowFor[2]`, `pauseT[2]`, `lostT[2]`, `drifting[2]`, `followers[2]`, `followArrived[2]`, ring `trail[2] = Float32Array(3 * 256)`, `trailHead[2]`, `trailN[2]`, `trailLast[2] = Vector3` (preallocated).
Drifting when: `h.visible && h.active && !h.submerged && !h.pinch.active && !h.grabbed && h.open && h.palm.normal.y > RIB.normalY && !h.still && h.palm.speed in [RIB.speedMin, RIB.speedMax] && h.palm.speedH >= 0.6 * h.palm.speed`. If drifting: `slowFor += dt; pauseT = 0`. Else if the only failure is `palm.speed < speedMin` or `h.still` (a pause) and `pauseT < RIB.pauseGrace`: `pauseT += dt` (keep slowFor). Else if `!h.visible` and `lostT < RIB.lostGrace`: `lostT += dt`. Else `slowFor = 0` and release all followers of that hand (WANDER, `cooldown = 4`), clear the trail. Any `palm.speed > RIB.breakSpeed`, pinch, submersion, or a closed hand releases immediately. Recruit while `slowFor > RIB.recruitAfter`, every `RIB.recruitEvery` s (own timer `followT[hi]`), the nearest WANDER firefly with `cooldown <= 0` within 14 m of the palm, up to `RIB.max` per hand: `state = FOLLOW; followHand = hi; followIdx = k (0..max-1, first free)`. Keep a `Int16Array(2 * max)` of follower slots so `followIdx` is unique per hand.
Trail: `T = palm.position + palm.normal * RIB.lift`; push a sample when `T.distanceTo(trailLast) >= RIB.sampleStep` (distance-based, so the strand keeps 8 cm spacing at any speed; ring holds 5 m). Follower `k` targets sample `head - RIB.spacing * (k + 1)` (clamped to the oldest sample when the trail is shorter) plus a seeded +/-0.03 m offset. Inbound followers (> `RIB.inbound` from their target) head for the live `T` at <= 0.6 m/s; steering is the APPROACH easing (`sp = min(0.6, 0.08 + 2.2 d)`, `k = min(1, dt * 3.5)`, the same wobble). Brightness: inbound `max(blink(i), 0.35)`; on the strand (d < 0.3) `0.7 + 0.2 * sin(t * 2.1 + seed * 31)` and count it as arrived. Followers stay while the hand remains open, visible, not submerged, not pinching and below `breakSpeed` — including when it stops.
Hand-off: the frame a hand with followers becomes `openStill`, for each free `SLOT_JOINTS` slot take the nearest follower: `state = APPROACH; slotHand = hi; slotIdx = s; slots[hi][s] = i; followHand = -1` (instant landings via the existing path); the rest hover on their samples. The existing repel (`speed > 0.7` within 0.6 m) scatters them like anything else. Accumulate `followCentroid` (Float32Array(6)) per hand from arrived followers in the main loop, no allocation.

## Sound (sfx.js)
`on('fireflyfollow', e)`: first arrival (count 1) -> `triggerBell(S, { midi: pitchFor(S, 2, 6), pos: e.pos, gain: 0.10, dur: 1.2, kind: 'glass', wet: 0.5 })`; eighth -> `pitchFor(S, 4, 6)` gain 0.12. Continuous 'hand voice' per hand (persistent, created in start: two sine oscillators -> lowpass 2500 Hz -> gain 0.0001 -> `api.spatial({ refDistance: 1.0, rolloff: 1.2, out: S.out.chimes })`): in the 30 Hz block, `pa.position` = that hand's `followCentroid`, `gain.setTargetAtTime(0.03 * smoothstep(0, 10, ctx.fireflies.followArrived[hi]), now, 0.3)`; in the 4 Hz block retune to `mtof(84 + mod12(currentChord.root))` and `mtof(84 + mod12(currentChord.fifth))` with `setTargetAtTime(..., 0.3)`. Kill in stop().

## Hint (hints.js, appended)
`{ id: 'ribbon', text: 'move an open hand slowly and they follow', after: 130, done: (ctx, s) => s.followed, ready: (ctx, s) => s.touchedWater }`; `s.followed` from the first 'fireflyfollow'.

## Edge cases
Tracking loss: 0.4 s grace, then release. Hand in water: released. Pinch (locomotion or grab): released — rig-local `palm.speed` also means gliding never counts as drifting. Both hands: independent, 16 each. Leave pose: needs still hands with normals horizontal; excluded by `normal.y > 0.15` and `!still`. Buds-turn needs a still hand; a drifting hand only makes buds lean. Landed fireflies on a drifting hand: unaffected (they leave above 0.35 m/s as today). Timejump: nothing to clamp (no absolute timers).

## Harness
main.js: add `'fireflyfollow'` to the eventLog list; stats() gains `fireflyFollowers: [ctx.fireflies.followers[0], [1]]`, `fireflyFollowArrived: [...]`. Scenario, after the escort steps (hands free): park the left hand `setHand('left', [-0.3, 1.25, -0.45], 0, { pitchDeg: 0, rollDeg: 0, curl: 0.6 })` (not open, attracts nothing). Right hand palm up, 4 legs of 96 frames moving the wrist between world x 0.10 and 0.50 (dx 0.00417/frame = 0.15 m/s), y 1.30, z -0.45, `{ pitchDeg: 0, rollDeg: 180, curl: 0.02 }` (stillDisp over 0.5 s = 0.075 > 0.03, so never `still`; speedH = speed). After the 384 frames plus `frames(36)`: `step('firefly-ribbon', stats().fireflyFollowers[1] >= 3 && stats().fireflyFollowArrived[1] >= 2 && events().some(e => e.type === 'fireflyfollow' && e.detail.hand === 'right') && no 'fireflyland' with hand 'right' since the sweep began)`. Then hold the hand still at its last pose for 120 frames: `step('ribbon-handoff', a 'fireflyland' with detail.hand === 'right' appears within those frames)` (a fresh recruit from 3.6 m needs ~7 s, so this proves the hand-off). Move the right hand to `[0.25, 1.25, -0.4]` with `curl: 0.6` afterwards.
