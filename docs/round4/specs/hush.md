# Hush

Rest an open palm flat on the water and keep it there: after a moment a circle of perfect stillness spreads from under the hand, ripples die at its edge and the stars come up through the glass-still disc. The plankton go quiet inside it, a low bowl note holds, raindrop notes begin to fall, and lifting the hand lets the lake breathe again. Zero draw calls (two uniforms), a new ~200-line module `src/world/hush.js` registered in `src/world/index.js` after `fireflies` (before `leave`).

## Plumbing (order-safe)
`player.js` writes `ctx.water.calm` before any module runs and wavesim/water run first, so hush must not depend on module order. wavesim.init creates `ctx.water.hush = { data: new Float32Array(8), strength: 0 }` (two vec4: uv centre x, y; radius in uv units; strength) and a uniform `uHush: { value: ctx.water.hush.data }`; wavesim.update uses `calm = max(ctx.water.calm || 0, 0.6 * ctx.water.hush.strength)` for `uDamping`. water.init adds `uHush: { value: new Float32Array(8) }` (world metres: x, z, radius, strength) and water.update copies `ctx.water.hushWorld` (a Float32Array(8) the hush module fills; wavesim allocates it too as `ctx.water.hushWorld`) and uses the same max for `uCalm`. The hush module writes both arrays each frame (one-frame lag, no allocation). Guard: if `ctx.water.hush` is missing, hush.init throws (module skipped).

## Gesture (hush.js)
Constants `HUSH = { normalY: -0.8, yMin: -0.05, yMax: 0.03, hold: 0.6, holdDecay: 3, tauIn: 0.8, tauOut: 1.2, r0: 0.25, r1: 1.2, grow: 3.0, follow: 1.0, onAt: 0.05, offAt: 0.02, calmGain: 0.6 }`. Per hand a circle `{ x, z, r, s, hold, active, wasActive }`. Pose = `h.visible && h.active && h.open && h.palm.normal.y < HUSH.normalY && h.palm.position.y - level in [yMin, yMax] && h.still && !h.pinch.active && !h.grabbed` (`h.still` is computed regardless of submersion; the palm pads dip, which is expected). `hold += dt` while pose else `hold = max(0, hold - holdDecay * dt)`. When `hold >= HUSH.hold` and not active: activate with centre = palm xz, `r = r0`, `s = 0`, `growT = 0`. While active and pose: `s += (1 - s) * (1 - exp(-dt / tauIn))`; centre lerps toward the palm at `HUSH.follow` per second; `growT += dt; r = r0 + (r1 - r0) * easeOutCubic(min(1, growT / grow))`. When the pose breaks: `s += (0 - s) * (1 - exp(-dt / tauOut)); r = r0 + (r1 - r0) * s`... keep `r` from shrinking faster than `s` (use `r = max(r0, rGrown * s)`). Events: `'hush' { hand, pos: palm.clone() }` when `s` crosses `onAt` upward; `'hushend' { hand }` when it falls below `offAt` after being active (then active = false). Each frame write `ctx.water.hushWorld[hi*4..] = (x, z, r, s)` and `ctx.water.hush.data[hi*4..] = (frac(x / tile), frac(z / tile), r / tile, s)`; `ctx.water.hush.strength = max(s0, s1)`. Expose `ctx.hush = { strength, circles: [{ x, z, r, s, active }, ...], count }` (count = activations).

## Visual
wavesim fragment, after `vel` and before `hn`: `float hf = 0.0; for (int i = 0; i < 2; i++) { vec2 dv = vUv - uHush[i].xy; dv -= floor(dv + 0.5); float r = max(uHush[i].z, 1e-4); hf = max(hf, uHush[i].w * (1.0 - smoothstep(0.6 * r, r, length(dv)))); } vel *= 1.0 - 0.7 * hf;` and after the disturbance loop `hn *= 1.0 - 0.15 * hf;` (waves entering the circle die within a few steps; height relaxes flat). water fragment, after `dPlayer`: `float hf = 0.0; for (int i = 0; i < 2; i++) { vec2 hd = p - uHush[i].xy; float hr = max(uHush[i].z, 1e-3); float hl = length(hd); hf = max(hf, uHush[i].w * (1.0 - smoothstep(0.6 * hr, hr, hl))); }` then `nxy *= 1.0 - 0.92 * hf;` (mirror), after `F` is computed `F = max(F, 0.32 * hf);` (a deliberate gentle boost so the stars and aurora come up through the disc at the steep viewing angle), `bio *= 1.0 - 0.9 * hf;`, and the spreading edge: `col += uPlankton2 * 0.10 * uHush[i].w * (1.0 - smoothstep(0.0, 0.035, abs(hl - hr))) * (1.0 - hr / 1.2)` accumulated in the loop. Both water meshes share the uniforms. Verify in a harness screenshot that the disc is not a grey plate; if it is, drop 0.32 to 0.22.

## Sound
sfx.js: `on('hush', e)`: `midi = 48 + mod12(currentChord.root)`; `triggerBell(S, { midi, pos: e.pos, gain: 0.22, dur: 6, kind: 'ceramic', attack: 0.12, wet: 0.5, tag: 'hush' })` + `layer = pickTuned(S, BOWLS, midi + 12)` at gain 0.16 via playAt. Calm drone gate in the 4 Hz block: `calm = max(ctx.water.calm, ctx.calm, ctx.hush?.strength || 0)`. music.js: on 'hush' `S.hushing = true`, on 'hushend' `S.hushing = (ctx.hush?.strength || 0) > 0.02`; raindrop gate becomes `calmWorld = (energy < 0.15 && !anySub) || S.hushing`, next-drop interval `3 + 4 * rng()` s while hushing (the hand is submerged, so the old gate alone would never let them fall). ambience.js: nothing (crickets keep going; the swish falls silent by itself).

## Edge cases
Tracking loss: pose false, s decays over 1.2 s. Pinch breaks the pose (pull-the-world untouched; a lantern within 13 cm of the pinch point is grabbed as before). Leave: needs neither hand submerged and palms facing each other — a hush hand is submerged with its normal down. Fireflies: submerged hand, no recruiting. Buds-turn excludes submerged hands; the existing touch rule may still open a bud under the palm (fine). Ribbon excluded (palm up, moving). Both hands: two circles. Locomotion active: pinching. A palm pressed deeper than 5 cm gets nothing (calibration puts the surface where the eyes expect).
