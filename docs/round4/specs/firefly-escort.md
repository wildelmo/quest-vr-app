# Firefly escort, and the lake passes it on

Let a lantern go and up to ten nearby fireflies (including any resting on the releasing hand) lift off with it, spiralling round the flame as it rises, the flame flaring with them. A few metres up they spill away as sparks and their home cloud flashes in step for a while. When that lantern finally becomes a star, the news rolls back across the water: a wave of firefly flashes spreads from where you stand at walking pace, every open lotus it passes brightens and restates its note, and the crickets pause for a breath. No new gesture; zero draw calls.

## Firefly state numbers (shared with 'firefly-ribbon')
`ESCORT = 4` (this feature), `FOLLOW = 5` (ribbon). Both must be excluded from the synchrony pass (`state !== WANDER && state !== SCATTER` already does), from LANDED/APPROACH handling, and cleared by the repel loop and every `releaseSlot` path (`escortL[i] = -1`).

## Escort (src/world/fireflies.js)
Constants `ESC = { max: 10, wanderRange: 3.0, handRange: 0.6, spillAt: 4.2, orbitA: 2.6, orbitR: 0.14, orbitRJit: 0.12, speedMax: 1.0, kick: 6, kickGain: 2.0 }`. Arrays: `escortL = new Int8Array(N).fill(-1)`, scratch `escIdx = Int16Array(10)`, `escD = Float32Array(10)`; `S.syncKick = new Float32Array(3)`, `S.kickedCloud = -1`, `escortCount`.
On `'lanternrelease' { lantern: L }` (subscribe in init): nearest-first insertion into the fixed 10-slot arrays of (a) WANDER fireflies with `cooldown <= 0` within `ESC.wanderRange` of `L.position`, (b) LANDED/APPROACH fireflies within `ESC.handRange` of it (the releasing hand). For each recruit: `releaseSlot(i); state[i] = ESCORT; escortL[i] = L.i; cooldown[i] = 0`. If count > 0 emit `'fireflyescort' { pos: L.position.clone(), count, lantern: L }`.
Per-frame ESCORT branch (in the main loop): `L = ctx.lanterns.list[escortL[i]]`; if `!L || L.state !== 'rising' || L.riseTime > ESC.spillAt` -> spill (below). Else `a = t * ESC.orbitA + seed[i] * 6.283; r = ESC.orbitR + ESC.orbitRJit * seed[i]; target = (L.position.x + cos(a) * r, L.position.y + 0.05 + (seed[i] - 0.5) * 0.25, L.position.z + sin(a) * r)`; desired speed `min(ESC.speedMax, 0.15 + d * 3)`; velocity lerp `k = min(1, dt * 5)`; `bright[i] = max(blink(i), 0.55)`; this state bypasses the yMax band clamp. Count escorts per lantern into a scratch `Int8Array(24)` zeroed each frame and write `L.escorts = n` on every rising lantern record (cross-module field; document in both file headers).
Spill (one-shot per lantern via a `spilled` flag on the lantern record, reset in `respawnFar` and `onGrab`): for each escort of that lantern: `vel = outward * 0.9 + (rnd - 0.5) * 0.3, vy = -0.25 + rnd * 0.3; state = SCATTER; timer = t + 1.0 + rnd * 0.6; cooldown = 4; bright = 1; escortL = -1`; `S.syncKick[k] = ESC.kick` for the cloud most escorts came from (`homeIdx`), `S.kickedCloud = k`; emit `'fireflyspill' { pos, count, lantern }`. In the sync pass: `syncKick[k] -= SYNC.dt` and while `> 0`, `kg[k] = max(kg[k], ESC.kickGain * SYNC.kMax * R * SYNC.dt)` — with K about 4.8 rad/s against a 2–4.5 rad/s spread the cloud locks to R ~0.8 within a few seconds.
lanterns.js rising branch: `L.flame` target becomes `1 + 0.3 * min(1, (L.escorts || 0) / 4)` (instead of the plain 1).

## The lake passes it on
fireflies.js subscribes to `'lanternstar'`: `S.waveAt = t + 0.8; S.waveOX/OZ = headWorld.x/z` (the star's own sparkle strikes first). On the first update with `t >= S.waveAt` (`WAVE = { speed: 2.5, hold: 6, delay: 0.8 }`): one O(N) pass over non-steady WANDER/SCATTER fireflies: `d = hypot(x - ox, z - oz); tPeak = t + d / WAVE.speed; rise = FLASH.rise * (0.85 + 0.3 * seed[i]); phase[i] = ((rise - tPeak) % pd + pd) % pd` so each flash peaks exactly as the 2.5 m/s front reaches it; `S.waveHold = WAVE.hold` (in the sync pass while waveHold > 0: `kg[k] = 0` for all clouds, and it overrides syncKick); fill `ctx.fireflies.wave = { fired: true, t0: t, ox, oz, speed, count, sample: Int16Array(32), sampleT: Float32Array(32) }` with the first 32 rewritten fireflies of cloud 0 and their `tPeak`; emit `'lakewave' { pos: new Vector3(ox, level, oz), count }`. lotus.js subscribes to `'lakewave'`: for every flower with `f.open`, `f.waveAt = t + hypot(f.position.x - ox, f.position.z - oz) / 2.5` (else -1); in the instance loop `sf = f.waveAt > 0 ? sin(PI * clamp((t - f.waveAt) / 2.0, 0, 1)) : 0`, `surgeF = max(surge, 0.7 * sf)` replaces `surge` for that instance's glow size/gain; `uSurge` stays the global max. Hand-resting fireflies (LANDED/APPROACH/ESCORT/FOLLOW) are skipped by the pass.

## Sound
sfx.js: `'fireflyescort'` -> for `k < min(count, 5)`: `triggerBell(S, { midi: pitchFor(S, k, 6), pos, gain: 0.07, dur: 0.9, kind: 'glass', when: now + 0.05 + k * 0.09, wet: 0.5, tag: 'escort' })`. `'fireflyspill'` -> four descending `pitchFor(S, 4 - k, 6)` glass bells 70 ms apart gain 0.05 + `noiseBurst({ type: 'highpass', freq: 4000, q: 0.7, dur: 0.3, gain: 0.03 })`. `'lakewave'` -> for each `f` in `ctx.lotus.flowers` with `f.open`: `triggerBell(S, { midi: pitchFor(S, f.note, 5), pos: f.bud, gain: 0.10, dur: 2.6, kind: 'glass', attack: 0.03, wet: 0.7, when: now + hypot(f.bud - head).xz / 2.5, tag: 'wave' })` plus one breath `noiseBurst({ kind: 'pink', type: 'lowpass', freq: 600, q: 0.5, dur: 1.5, gain: 0.05, pos: head })`. ambience.js: `S.offs.push(ctx.events.on('lakewave', () => startle(2, 4)))`. music.js: nothing (the existing release swell and aurora voice already underlie it).

## Hint (hints.js, appended)
`{ id: 'escort', text: 'let a lantern go with fireflies on your hand', after: 200, done: (ctx, s) => s.escorted, ready: (ctx, s) => s.fireflyLanded && s.released && nearestLantern(ctx) < REACH + 0.15 }`; `s.released` from 'lanternrelease', `s.escorted` from 'fireflyescort' with count >= 3.

## Edge cases
Re-grab within 3 s: `L.state` becomes 'held' -> escorts spill at once. Timejump: ESCORT keys on `L.riseTime` (nothing to clamp); waveAt/waveHold are clamped to `nt + 1`. Escort recruiting skips FOLLOW fireflies and vice versa. Fast hand scatters escorts like anything else. Wave hold wins over a concurrent kick.

## Harness
main.js: add `'fireflyescort', 'fireflyspill', 'lakewave'` to the eventLog list; stats() gains `fireflyEscorting: ctx.fireflies?.escortCount`. Scenario, right after the existing 'firefly-landed' step (right hand palm-up at `[0.3, 1.3, -0.45]`): `L2 = nearest floating lantern`; move the wrist over 144 frames (<= 0.3 m/s so landed fireflies stay) keeping `{ pitchDeg: 0, rollDeg: 180, curl: 0.02 }` to `[L2.x, L2.y + 0.15, L2.z + 0.10]`; ramp `pinch` 0 -> 1 over 24 frames; assert a 'grab'. Lift 0.40 m over 54 frames (pinch 1), then pinch 0 at the top; `frames(4)`; `step('firefly-escort', events().some(e => e.type === 'fireflyescort' && e.detail.count >= 1) && stats().fireflyEscorting >= 1)` (fallback holds even if the landed ones left: cloud 0's fringe is inside 3 m). Park the hand (`curl: 0.6`); `frames(180)`; `step('firefly-spill', 'fireflyspill' present && stats().fireflyEscorting === 0)`; `clock.step = 0.1`; poll up to 80 frames for `max(ctx.fireflies.coherence[ctx.fireflies.kickedCloud]) > 0.5`; keep stepping (still 0.1) polling `events()` until a new 'lanternstar' appears (<= 320 frames); set `clock.step = 1/36`; run frames until `ctx.fireflies.wave.fired` (<= 40); copy `sample/sampleT`; then for 150 frames record, per sampled index k, `max(brightness[sample[k]])` over frames with `|ctx.time.t - sampleT[k]| <= 0.12`; `step('lake-wave', 'lakewave' logged with count >= 100 && >= 75% of the 32 samples peaked > 0.6 && ctx.lotus.flowers.some(f => f.open) ? ctx.lotus.flowers.some(f => f.waveAt > 0) : true)`.
