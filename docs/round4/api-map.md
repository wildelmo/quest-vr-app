# NOCTURNE input-area API map

Paths are under `/home/user/quest-vr-app/`. Imports: `import * as THREE from 'three'` (import map → `./vendor/three/three.module.js`, `three/addons/`). Shaders live in `src/shaders/<module>.js` as exported GLSL string consts.

## 1. World module registration and lifecycle (`src/world/index.js`, `src/main.js`)

- A module is a plain object `{ name: string, init(ctx), update(ctx, dt) }` exported as `export const <name> = {...}` from `src/world/<name>.js`. Add it to `WORLD_MODULES` in `src/world/index.js`: current order `[wavesim, water, sky, aurora, plankton, drips, shore, mist, lotus, lanterns, fireflies, leave, hints]` (wavesim first; hints last). `?extra=<name>` loads an unregistered `src/world/<name>.js` (must export `mod[name]` or default); `?only=a,b` restricts.
- `init(ctx)` is `await`ed once at boot, in order; a throw is caught and reported (`showError`), module skipped. No other hooks exist (no `onXRStart`); modules subscribe to `ctx.events` `'xrstart'`/`'xrend'`/`'desktopstart'` themselves. Instance state convention: `this._ = {...}` in init.
- Per-frame order in `renderer.setAnimationLoop((now, frame) => ...)`: `ctx.time` update → `ctx.view.pixelScale` → `ctx.hands.update(frame, dt)` → `ctx.playerCtl.update(dt)` → each `m.update(ctx, dt)` in registration order → `ctx.energy = max(0, ctx.energy - CONFIG.energy.decay*dt)` → `ctx.audio.update(dt)` → `renderer.render`. Each stage is guarded: a throw sets `m._err = true` and that module never updates again. `dt` is clamped to `[0.0001, 0.1]` and derived from the loop's `now` argument.

## 2. `ctx` fields

`ctx = { renderer, scene, camera, player (THREE.Group 'player', owns camera and XR hands), time: { t, dt, frame, now }, water, hands, energy (0..1, decays 0.02/s), events (Events), audio, assets, grabbables: [], quality: { tier: 'desktop'|'quest2'|'quest3', isQuest, panorama, simSize, particleScale (0.7 on quest2), anisotropy }, harness (bool, `?harness`), debug, xr, errors: [], view: { pixelScale, eyeHeightPx }, mode: 'landing'|'desktop'|'xr', calm (0..1, from player), seated, xrBlurred, xrInputs: { hands, controllers }, eventLog, modules, playerCtl, fps }`.

`ctx.water = { level (0.95), tileSize (16), simTexture, simSize, swell(x, z, t) → metres, calm (0..1), disturb(x, z, radius, strength), lastDisturb, simSnapshot(), mesh, nearMesh, uniforms }`.

`ctx.assets.tex` keys: `noise`, `paper`, `glowSoft`, `glowFirefly`, `panorama` (+ others). Module-exposed: `ctx.lanterns`, `ctx.lotus`, `ctx.fireflies`, `ctx.drips`, `ctx.leave`, `ctx.sky = { moonDirWorld, moonAbove, moonAltitudeDeg, auroraTint, addLanternStar(dirWorld), lanternStarCount(), meteorShower, ... }`, `ctx.aurora = { intensity }`, `ctx.shore = { heightAt(x,z), groundAt(x,z), islets, reedPatches, wind }`, `ctx.mist`, `ctx.music` (set when audio starts).

## 3. Hands (`src/core/hands.js`)

Exports: `JOINT_NAMES` (25 WebXR names), `TIP_NAMES = ['index-finger-tip','middle-finger-tip','ring-finger-tip','pinky-finger-tip','thumb-tip']`, `WATER_JOINTS = ['wrist','thumb-tip','index-finger-tip','middle-finger-phalanx-proximal','middle-finger-tip','ring-finger-tip','pinky-finger-tip']`, `createHands(ctx)` → `{ left, right, list: [left, right], byHandedness, any(fn), update(frame, dt), enableDesktop(), setDesktopHand({x,y,pinch,submerged}), materials, debugInfo() }`.

Per-hand state (all world-space metres/seconds unless noted; written every frame by `finishState`):

| field | type | meaning |
|---|---|---|
| `handedness` | `'left'|'right'` | |
| `tracked` | bool | joints valid this frame (false when `ctx.xrBlurred`) |
| `visible` | bool | tracked, or lost < `CONFIG.hands.lostFade` (0.35 s) |
| `alpha` | 0..1 | confidence ease (up τ 0.12 s, down 0.35 s) |
| `active` | bool | `tracked && alpha > 0.5` — gate for gestures |
| `lostFor`, `everTracked`, `source` | s, bool, `'xr'|'desktop'|'none'` | |
| `joints[name]` | `{ position (Vector3 world), local (rig-local), prev, velocity (Vector3, rig-local m/s, clamped 4), radius (m), valid }` | |
| `palm` | `{ position (= middle-finger-metacarpal, else wrist), normal (unit, points out of the palm; (0,-1,0) for a palm-down hand), velocity (world, includes rig velocity), velocityLocal (rig-local), speed (m/s), speedH (horizontal), filtered }` | |
| `tips[5]` | Vector3[] in `TIP_NAMES` order | |
| `speed` | m/s | max joint speed |
| `submerged` | bool | hysteresis: on when any `WATER_JOINTS` depth > 0.01, off at depth ≤ 0 |
| `submergedDepth`, `submergedJoints[]` | m, joint objects | |
| `enteredWater`, `leftWater` | bool | one-frame edges (also emit `handenter`/`handexit`) |
| `curl[4]`, `meanCurl` | 0..1 | index,middle,ring,pinky |
| `open` | bool | every curl < `curlOpen` 0.35 |
| `grasp` | bool | meanCurl hysteresis 0.75/0.60 |
| `pinch` | `{ active, justStarted, justReleased, point (Vector3: tip midpoint, or palm+3.5 cm along normal for grasp), strength 0..1, distance (thumb–index m), os (Meta select), onFrames, offFrames, kind: 'none'|'pinch'|'grasp' }` | active needs `active` hand; on = os pinch or `distance < pinchOn` 0.020 for 2 frames; off = `> pinchOff` 0.035 for 3 frames |
| `stillDisp`, `still` | m, bool | max displacement of filtered palm over `stillWindow` 0.5 s < `stillDisp` 0.03 |
| `stillFor` | s | still && !submerged accumulated |
| `openStill` | bool | `open && stillFor > stillTime (1.0) && !submerged` |
| `attraction` | 0..1 | `smoothstep(stillFor, 0.3, 1.5)` when open && !submerged |
| `grabbed` | grabbable or null | |

Lost tracking: after `graceGrab` 1.0 s a held grabbable gets `onRelease(hand, zero, { lost: true })` and `pinchend { lost: true, released: true }`; `submerged` clears after 0.3 s.

Grabbable protocol (`ctx.grabbables` entries): `{ position: Vector3, radius, active (false = ignored), held (hand or null), warm (false = no lantern warmth on the hand), onGrab(hand), onRelease(hand, velocity: Vector3, { lost }) }`. On `pinch.justStarted` the nearest with `distanceTo(pinch.point) - radius < grabRadius` (0.13) is grabbed (`grab` event); a tip pinch with no target emits `pinchmiss` and a spark. Player locomotion only engages when `pinch.kind === 'pinch' && !grabbed`, so a new grabbable in reach is the only sanctioned way to give a pinch a meaning.

Draw calls owned: 2 sphere InstancedMesh (fallback), 1 Points (fingertip glow + 2 pinch sparks).

## 4. Player (`src/core/player.js`)

`createPlayer(ctx)` → `{ update(dt), enableDesktop(), look(yawDeg, pitchDeg), setLeave(v 0..1), state, velocity (getter, rig world velocity Vector3), calm (getter) }`. `playerCtl.state = { speed (glide m/s), headWorld (Vector3), headVelocity (Vector3), velocity (= rigVel), calibrated, seated, eyeHeight, holding (a pinch holds the world), pulling (dead zone passed, rig follows palm), turning, turnRate (rad/s), pullSpeed }`. Sets `ctx.calm` (rises 0.25/s when head < 0.08 m/s, hands `stillDisp ≤ 0.05`, no pull) and `ctx.water.calm`. Emits `calibrated { eyeHeight, seated, rigY }`. ## 5. Events (`src/core/events.js`)

`class Events { on(type, fn) → off(); once(type, fn); off(type, fn); emit(type, payload = {}) }`. Handlers are try/caught. Logged event names in `main.js` (`ctx.eventLog`, `__nocturne.events()`): `grab, pinchstart, pinchend, pinchmiss, handenter, handexit, lanterngrab, lanternrelease, lanternsplash, lanternstar, starborn, lotusbloom, lotuschord, fireflyland, calibrated, xrstart, xrend, moonset, meteor, audiostart, leave, drip` — **a new event must be appended to that array to be visible to the harness**. `summarize()` keeps `index, note, grabbed, kind, lost, released, seated, eyeHeight, hasHands, count, speed`, `hand.handedness` → `hand`, and `pos.{x,y,z}` → `pos: [x,y,z]`. Unlogged: `timejump { t }`, `inputsourceschange`, `xrblur`, `xrfocus`, `desktopstart`.

Payloads: `grab { hand, grabbable }`, `pinchstart { hand, grabbed, kind }`, `pinchend { hand, released, lost? }`, `pinchmiss { hand, point }`, `handenter { hand, speed }`, `handexit { hand }`, `lanterngrab|lanternrelease { pos, hand, lantern }`, `lanternsplash { pos, lantern }`, `lanternstar { dir, pos, lantern }`, `starborn { dir, count }`, `lotusbloom { index, note, pos, color }`, `lotuschord {}`, `fireflyland { pos, hand, joint, index }`, `drip { pos, hand, bright }`, `leave {}`, `xrstart { session, hasHands }`.

Sound handlers (`src/audio/sfx.js`) accept `pos` as anything with numeric `x,y,z` (`hasXYZ`) — a `Vector3` or `{x,y,z}`; they fall back to `e.hand.palm.position` then the head. Do not reuse a scratch vector for `pos` (lotus/lanterns pass `.clone()`).

## 6. Audio subsystem pattern (`src/audio/*`)

`registerAudio(ctx)` calls `ctx.audio.add(sub)` for `ambience, music, sfx`. A subsystem is `{ name, _s, start(api, ctx), update(api, ctx, dt), stop() }`; `start` runs once the AudioContext is unlocked (`api.started`), so subscribe there with `S.offs.push(ctx.events.on(name, fn))` and unsubscribe in `stop`. `api` helpers: `api.context`, `api.bus`, `api.buses.{bed,world,chimes,music}`, `api.wet` (reverb), `api.spatial({ pos, refDistance, rolloff, hrtf, maxDistance, out }) → PositionalAudio with .input, .position, .dispose()`, `api.play(name, { pos, gain, rate, detune, loop, refDistance, rolloff, hrtf, out })`, `api.noise('white'|'pink', seconds)`, `api.pitch(name)`, `api.buffer(name)`, `api.now()`. Loaded samples are limited to `AUDIO_USED` in `src/audio/index.js`. Deterministic RNG when `ctx.harness`.

`sfx` exports `fmBell(api, ctx, opts)` and `sfx.bell({ midi, pos, gain, dur, kind: 'glass'|'ceramic', index, when, wet, detune, refDistance, attack, tag })`; internal `noiseBurst(S, { pos, when, dur, gain, type, freq, q, sweepTo, kind, refDistance })` and `playAt(S, name, pos, opts)`. Existing reactions: `lotusbloom` → bell on `pitchFor(note, 5)` + tuned bowl; `fireflyland` → high ting/bell; `lanterngrab` → 90 ms rustle; `lanternrelease` → whoosh + low ceramic bell; `lanternsplash` → splash sample; `handenter` → sweep burst (+ splash if `speed > 0.5`); `handexit` → 2–3 ticks; `drip` → 28 ms plip; `pinchmiss` → 20 ms tick. Continuous: per-hand swish from `h.submerged`, `h.palm.speed`, `h.submergedDepth`; glide rush from `playerCtl.state.speed`; calm drone when `max(ctx.water.calm, ctx.calm) > 0.5`. `music`: `lanternrelease` → pad swell, `lotuschord` → `pad_bioluminescence`; raindrop bells when `ctx.energy < 0.15` and no hand submerged. `ctx.music = { rootMidi 62, penta [0,3,5,7,10], chords, currentChord { name, root, fifth, intervals, pcs, midi }, breathing, scaleNote(degree, octave), pitchFor(degree, register=5), isConsonant(midi), nearestConsonant(midi), advance(), raindrop(), breathe(), requestSwell(name, gain) }`. `ambience`: `lanternsplash`/`lotuschord` → `startle(min,max)` silences crickets; a submerged hand with `palm.speed > 1.0` also startles.

## 7. Hints (`src/world/hints.js`)

`HINTS` entries: `{ id, text, after (s since session start), done(ctx, s) → bool (learned; persisted 24 h in localStorage 'nocturne.hints', not in harness), ready(ctx, s) → bool }`. Repeating status hints `{ id, text, repeat: true }`: `LEAVE`, `SHOW_HANDS`, `NO_TRACKING`, `CONTROLLERS`. State `s = { handsSeen, touchedWater (handenter), grabbed (grab), fireflyLanded, moved, turned, bloomed, sessionStart, ... }`. Selection each frame: `LEAVE` if `ctx.leave.progress > 0.15` (preempts anything); else status hints; else, if `t > st.cooldownUntil`, the first `HINTS` entry not learned/done, with `elapsed ≥ after`, shown < 3 times, `ready`. A shown hint clears when `done` (cooldown 20 s) or after 14 s (cooldown 45 s). One canvas plane, 1 draw call, placed 1.05 m ahead at `water.level - 0.015`. To add a hint: push into `HINTS`, add its `s` flag and event listener in `init`.

## 8. Wave sim (`src/world/wavesim.js`)

`ctx.water.disturb(x, z, radius, strength)` queues (max 64/frame, 16 applied) a zero-mean Laplacian-of-Gaussian push; `radius` clamped 0.02–0.6 m; the sim clamps height to ±0.6. Values in use: hand joints `radius = j.radius*2.2+0.03`, `strength = speed*0.075*(0.35..1)` capped 0.16; body `0.28, ≤0.05`; lotus bloom `0.18, 0.28`; lantern splash `0.14, 0.45`; lantern drop `0.12, 0.2`; held lantern under water `0.1, 0.08–0.38` every 0.25 s; floating hull `0.09, 0.012–0.042` every 0.5 s; drips `0.045, 0.035*(0.6..1)`, ≤6/frame. Plankton glow follows injection (visible above ~0.006).

## 11. Fireflies (`src/world/fireflies.js`)

N = `round(300*particleScale)`; typed arrays `pos, vel, bright, state (WANDER 0 / APPROACH 1 / LANDED 2 / SCATTER 3), slotHand, slotIdx, timer, stay, cooldown, period, phase, steady`; `ctx.fireflies = { count, landedCount, positions, brightness, states, homes, coherence }`. ## 13. Leave (`src/world/leave.js`)

## 14. Harness (`tools/harness/`)

`window.__fakeXR.setHandPose('left'|'right', { position: [x,y,z], yawDeg, pitchDeg, rollDeg, pinch 0..1|bool, curl 0..1, spread 0..1, visible })` — an override that wins over the timeline until `clearOverrides()`. Frame: WebXR `local-floor` = **rig-local** (floor y=0, head at (0,1.6,0), −Z forward); world = rig-local + `ctx.player.position` (scenario's `setHand` subtracts `window.__nocturneCtx.player.position`). After calibration the rig y puts the water 0.60 m (standing) / 0.45 m (seated, eye < 1.35) below the eyes; in the harness head = 1.6 m so water ≈ 1.0 m in rig-local terms (world `level` 0.95). `position` is the wrist; fingers extend along −Z (~0.17 m), rest pose palm faces −Y (down), thumb −X (right hand; left mirrored). `qypr`: yaw about +Y, then pitch about local +X (positive = fingers up), then roll about local +Z; `rollDeg: 180` → palm up. Pinch: `pinch: 1` drags thumb/index tips together (distance 0 → `selectstart` at < 0.015, `selectend` > 0.03; app `pinchOn` 0.020). Open hand: `curl ≤ 0.1`, `pinch 0`. Grasp: `curl: 1`. ## world
# NOCTURNE "world" API map (src/world, src/core, src/audio, tools/harness)

## 1. Module registration and lifecycle
- `src/world/index.js` exports `WORLD_MODULES = [wavesim, water, sky, aurora, plankton, drips, shore, mist, lotus, lanterns, fireflies, leave, hints]`. Add a module by importing it and inserting it in this array; update runs in array order (wavesim first, hints last). Dev-only: `?extra=name` dynamic-imports `./world/${name}.js` and uses `mod[name] || mod.default`; `?only=a,b` filters the list.
- Module shape: `{ name: string, init(ctx), update(ctx, dt) }`. `main.js` calls only `await m.init(ctx)` (once, after assets/hands/playerCtl/xr exist) and `m.update(ctx, dt)` per frame. There are no `onXRStart`/`onXREnd`/`dispose` hooks; modules subscribe with `ctx.events.on('xrstart' | 'xrend' | 'desktopstart' | 'timejump', fn)` inside `init`. Each module is guarded: a throw in `update` sets `m._err = true` and the module is skipped thereafter (error pushed to `ctx.errors`, which fails the harness).
- Frame order: `ctx.hands.update(frame, dt)` → `ctx.playerCtl.update(dt)` → every module `update` → `ctx.energy = max(0, ctx.energy - CONFIG.energy.decay * dt)` (decay 0.02/s) → `ctx.audio.update(dt)` → `renderer.render`.
- Per-module private state convention: `this._ = {...}` (lotus/fireflies/drips) or `this._s` (wavesim).

## 2. ctx fields (set in main.js unless noted)
- `renderer: THREE.WebGLRenderer`, `scene: THREE.Scene` (fog `FogExp2(CONFIG.fog.color 0x060a12, density 0.0115)`), `camera: PerspectiveCamera` (child of `player`), `player: THREE.Group` (rig; `player.position`, `player.quaternion`, `player.rotation.y`).
- `time: { t (s, accumulated; jumps via setTime), dt, frame (int), now }`.
- `water: { level: 0.95, tileSize: 16, simTexture, simSize, swell(x, z, t) -> metres, disturb(x, z, radius, strength), calm (0..1, set by player.js), lastDisturb: Float32Array, simSnapshot(), mesh, nearMesh, uniforms }`.
- `hands`: `{ left, right, list: [left, right], byHandedness, any(fn), update, enableDesktop, setDesktopHand, materials, debugInfo() }` (createHands).
- `playerCtl.state: { speed (m/s glide), headWorld: Vector3 (world), headVelocity: Vector3, velocity (rigVel Vector3, world m/s incl. pulls), calibrated, seated, eyeHeight, holding, pulling (bool, hold engaged), turning, turnRate (rad/s), pullSpeed }`; also `ctx.playerCtl.velocity`, `ctx.playerCtl.calm`, `ctx.playerCtl.setLeave(v)`, `look(yawDeg, pitchDeg)`.

## 3. Hand state (`ctx.hands.list[i]`, from `makeState` in src/core/hands.js; all Vector3 in world metres unless noted; recomputed every frame in `finishState`)

- `submerged` (hysteresis: on when any WATER_JOINT depth > 0.01 below `water.level`, off at depth <= 0), `submergedDepth` (m), `submergedJoints: joint[]`, `enteredWater` / `leftWater` (true for exactly one frame; emit `'handenter'`/`'handexit'`).
- `curl: [index, middle, ring, pinky] 0..1`, `meanCurl`, `open` (every curl < `CONFIG.hands.curlOpen` 0.35), `grasp` (meanCurl hysteresis 0.75/0.60).
- `pinch: { active, justStarted, justReleased (one frame each), point: Vector3 (midpoint of index-tip/thumb-tip, or palm + 0.035·normal for a grasp), strength 0..1, distance (m), os (OS select event), onFrames, offFrames, kind: 'none'|'pinch'|'grasp' }`. - `stillDisp` (max filtered-palm displacement over `stillWindow` 0.5 s), `still` (disp < `stillDisp` 0.03), `stillFor` (s still while not submerged), `openStill` (open && stillFor > `stillTime` 1.0 && !submerged), `attraction` (smoothstep(stillFor, 0.3, 1.5) if open && !submerged else 0).
- `grabbed`: the grabbable currently held or null.
- Grabbable protocol (`ctx.grabbables.push(g)`): `g = { position: Vector3 (live reference), radius, active, held, warm, kind, onGrab(hand), onRelease(hand, velocity: Vector3 world, { lost: bool }) }`. Tracking loss > `graceGrab` 1.0 s calls `onRelease(hand, (0,0,0), { lost: true })`.

## 6. Water and wave sim
- `wavesim`: GPGPU ping-pong, `size = ctx.quality.simSize`, uv = `fract(worldXZ / 16)`, channels R height, G prev height, B afterglow (`uGlowDecay 0.975`), A instantaneous energy. `ctx.water.disturb(x, z, radius, strength)` queues (max 64/frame) into `MAX_DISTURB = 16` uniform slots per sim step; hands (`WATER_JOINTS` below the surface moving > 0.04 m/s, radius `j.radius*2.2+0.03`, strength ≤ 0.16) and the body (radius 0.28, strength ≤ 0.05) fill slots first. Radius clamped 0.02–0.6 m; kernel is a zero-mean Laplacian-of-Gaussian, height clamped ±0.6. `stepScale = clamp(dt*72, 0.6, 1.2)`; substeps `clamp(round(dt*72), 1, 3)`.
- Existing values: lotus bloom `disturb(x, z, 0.18, 0.28)`; lantern splash `(0.14, 0.45)`, drop landing `(0.12, 0.2)`, held-under `(0.1, 0.08..0.38)` every 0.25 s, hull ripple `(0.09, 0.012..0.042)` every 0.5 s within 9 m; drips `(0.045, 0.035*(0.6+0.4*bright))`, max 6/frame.
- `water.js`: far plane + 12 m displaced near patch (`renderOrder 2`, `uHeightScale 0.035` m/unit), sim visible within ~6–8.5 m of the head; `uLights[4]` = 4 brightest `ctx.lanterns.list` within 8 m. Analytic `ctx.water.swell(x,z,t)` (amplitude 0.012) is used by floating things only; the drawn surface is flat at `level`.
- Render-order convention: 1 under water (plankton, hints), 2 water, 3 on/above (mirrors on the surface, bodies, fireflies), 4 additive halos/flames/fingertips, 1000 vignette.

# NOCTURNE API map — audio, events, ctx, hands, world modules, harness

## Module contract (src/world/index.js, src/main.js)
- A world module is `export const <name> = { name: '<name>', init(ctx), update(ctx, dt) }` exported under its own name from `src/world/<name>.js`; add it to `WORLD_MODULES` in `src/world/index.js` (order = update order). `init` may be async (`await m.init(ctx)`); a throw excludes the module. `update(ctx, dt)` is wrapped by `guard`: the first throw sets `m._err` and the module is skipped forever. **No other hooks exist** (no onXRStart): subscribe to `ctx.events` for `'xrstart'`, `'xrend'`, `'desktopstart'`, `'timejump'`.
- Dev-only: `?extra=name` dynamically imports `./world/name.js` (expects export `name` or default); `?only=a,b` restricts the list.
- Frame order in `renderer.setAnimationLoop`: `ctx.time.{dt,t,frame,now}` updated → `ctx.view.pixelScale` → `ctx.hands.update(frame, dt)` → `ctx.playerCtl.update(dt)` → each module `update(ctx, dt)` in order `[wavesim, water, sky, aurora, plankton, drips, shore, mist, lotus, lanterns, fireflies, leave, hints]` → `ctx.energy = max(0, energy − 0.02·dt)` → `ctx.audio.update(dt)` → render. `dt` is clamped to `[0.0001, 0.1]` s.

## HandState (src/core/hands.js; `ctx.hands = { left, right, list:[left,right], byHandedness, any(fn), update, enableDesktop, setDesktopHand, materials, debugInfo }`)
Per hand, refreshed every frame in `finishState`:
- `handedness 'left'|'right'`; `tracked` (bool, this frame); `visible` (stays true `lostFade` 0.35 s after loss); `active` (tracked && alpha>0.5); `alpha` 0..1 confidence; `lostFor` s; `everTracked`; `source 'xr'|'desktop'|'none'`.
- `joints[name] = { position (Vector3 world), local (rig-local), prev, velocity (Vector3 rig-local m/s, lerped 0.5, cap 4), radius (m), valid }` for the 25 `JOINT_NAMES`; exports `JOINT_NAMES`, `TIP_NAMES = ['index-finger-tip','middle-finger-tip','ring-finger-tip','pinky-finger-tip','thumb-tip']`, `WATER_JOINTS = ['wrist','thumb-tip','index-finger-tip','middle-finger-phalanx-proximal','middle-finger-tip','ring-finger-tip','pinky-finger-tip']`.
- `palm = { position (world, = middle-finger-metacarpal joint), normal (Vector3 world unit, −Y of that joint; (0,−1,0) for desktop), velocity (world, incl. rig glide), velocityLocal (rig-local), speed (m/s, rig-local), speedH, filtered }`.
- `tips[5]` Vector3 world in TIP_NAMES order; `speed` = max joint speed (m/s).
- `submergedDepth` m (max of WATER_JOINTS below level), `submerged` (on >0.01 m, off ≤0), `submergedJoints[]`, `enteredWater`/`leftWater` (true for one frame).
- `curl[4]` 0..1 (index,middle,ring,pinky), `meanCurl`, `open` (all curl < 0.35), `grasp` (hysteresis 0.75/0.60).
- `pinch = { active, justStarted, justReleased (one frame), point (Vector3 world: midpoint of index/thumb tips, or palm+3.5 cm·normal for grasp), strength 0..1, distance m, os, onFrames, offFrames, kind 'pinch'|'grasp'|'none' }`. On: OS pinch or tip distance < 0.020 for 2 frames; off: > 0.035 for 3 frames.
- `stillDisp` m (max displacement of 120 ms-filtered palm over 0.5 s), `still` (≥6 samples, ≥0.3 s of history, disp < 0.03), `stillFor` s (still && !submerged), `openStill` (open && stillFor > 1.0 && !submerged), `attraction` = smoothstep(stillFor, 0.3, 1.5) if open && !submerged else 0.
- `grabbed`: grabbable object or null.
- Grab protocol (`handleGrabs`): on `pinch.justStarted` the nearest `ctx.grabbables` entry `g` with `g.active !== false && !g.held` and `g.position.distanceTo(pinch.point) − (g.radius||0) < 0.13` is grabbed: `st.grabbed = g; g.held = st; g.onGrab(st)`; emits `'grab' {hand, grabbable}`; else if kind==='pinch' emits `'pinchmiss' {hand, point}` (+ spark); always `'pinchstart' {hand, grabbed, kind}`. On `justReleased`: `g.onRelease(st, st.palm.velocity, {lost:false})`, `'pinchend' {hand, released}`. Tracking lost > 1 s while holding: `onRelease(st, (0,0,0), {lost:true})`, `'pinchend' {hand, lost:true, released:true}`. A grabbable: `{ position: Vector3, radius, active, held, warm, onGrab(hand), onRelease(hand, velocity, {lost}) }`. Locomotion (player.js `pulling`) uses a hand iff `h.active && h.pinch.active && h.pinch.kind==='pinch' && !h.grabbed`, so a pinch near a new grabbable is consumed by the grab.

## Events (payloads as emitted)
`'handenter' {hand, speed}` · `'handexit' {hand}` · `'grab' {hand, grabbable}` · `'pinchstart' {hand, grabbed, kind}` · `'pinchend' {hand, released, lost?}` · `'pinchmiss' {hand, point:Vector3}` · `'lotusbloom' {index, note (0..5), pos:Vector3 clone, color}` · `'lotuschord' {}` · `'lanterngrab' {pos, hand, lantern}` · `'lanternrelease' {pos, hand, lantern}` · `'lanternsplash' {pos, lantern}` · `'lanternstar' {dir (unit Vector3 from head), pos, lantern}` · `'starborn' {dir, count}` · `'fireflyland' {pos:Vector3, hand, joint, index}` · `'drip' {pos:Vector3, hand, bright}` (≤8/s) · `'calibrated' {eyeHeight, seated, rigY}` · `'xrstart' {session, hasHands}` · `'xrend'` · `'xrblur'`/`'xrfocus'` · `'desktopstart'` · `'timejump' {t}` · `'moonset' {}` · `'meteor' {dir}` · `'leave' {}` · `'audiostart'` · `'inputsourceschange'`.
`window.__nocturne.events()` only contains types in the list in main.js (`['grab','pinchstart','pinchend','pinchmiss','handenter','handexit','lanterngrab','lanternrelease','lanternsplash','lanternstar','starborn','lotusbloom','lotuschord','fireflyland','calibrated','xrstart','xrend','moonset','meteor','audiostart','leave','drip']`) — **add a new event type there** or it is invisible to scenarios. Entries: `{ type, t, detail }`, detail keeps keys `index, note, grabbed, kind, lost, released, seated, eyeHeight, hasHands, count, speed`, `hand` (handedness string), `pos` ([x,y,z] rounded). Cap 500.

## Audio engine (src/audio/engine.js, `createAudio(ctx)` → `ctx.audio`)
Fields: `listener, context, buses {bed, world, music, chimes}` (each GainNode with `.send` to reverb), `bus` (= world), `wet` (= reverb convolver input), `dry`, `running, started, unlocked, decoded, harness-aware`. Methods: `load()`, `unlock()`, `start()`, `fadeMaster(level, s)`, `update(dt)`, `add(sub)`, `buffer(name)`, `now()`, `stats() → {rms, peak, rmsDb, peakDb}`, `info(name)`, `pitch(name) → {midi, hz, reliable}|null`, `noise('white'|'pink', seconds)` (cached buffer), `spatial({pos, refDistance=1.5, rolloff=1.2, hrtf=false, maxDistance=60, out}) → PositionalAudio` with `.input` GainNode and `.dispose()`, `play(name, {pos, gain, rate, detune, loop, refDistance, rolloff, hrtf, out}) → {src, gain, node}|null` (pos: object with x,y,z via `pa.position.copy(pos)`). Subsystem contract: `{ name, start(api, ctx), update(api, ctx, dt), stop() }`, registered with `ctx.audio.add(sub)` (src/audio/index.js `registerAudio`; existing: `ambience, music, sfx`). `AUDIO_USED` Set lists the sample names that get decoded (`bowl_1..7, ting_1..4, splash_soft_1..4, plop_airy_1, whoosh_gentle, gong_1, wind_loop, water_loop_1, pad_*`). In harness, `maybeStart()` starts subsystems without waiting for decode; `--mute-audio` mutes output but the graph runs, so `window.__nocturne.audioStats()` returns real loudness.

### sfx (src/audio/sfx.js) — where a new reaction goes
Pattern: in `start`, `const on = (name, fn) => S.offs.push(ctx.events.on(name, ...))`. Handlers and payload expectations (`hasXYZ(p)` = numeric x,y,z; Vector3 or plain object both work): `lotusbloom` uses `e.pos, e.note, e.index`; `fireflyland` `e.pos` else `e.hand.palm.position`; `lanterngrab` requires `e.pos`; `lanternrelease` `e.pos`/hand; `lanternsplash` requires `e.pos`; `lanternstar` `e.dir` or `e.pos`; `handenter` requires `e.hand.palm.position`, optional `e.speed`; `handexit` `e.hand.palm.position`; `drip` requires `e.pos`, optional `e.bright`; `pinchmiss` `e.point` or `e.hand.pinch.point`. Tools inside sfx: `triggerBell(S, {midi, pos, gain, dur, kind:'glass'|'ceramic', index, when, wet, detune, refDistance, tag, attack})` (8-voice FM pool, exported as `sfx.bell(opts)` and `fmBell(api, ctx, opts)`), `noiseBurst(S, {pos, when, dur, gain, type, freq, q, sweepTo, kind, refDistance})`, `playAt(S, name, pos, opts)`, `pickTuned(S, names, midi, maxShift)`, `pitchFor(S, degree, register)` → consonant MIDI via `ctx.music.pitchFor`, `nearAtten(pos, head)`. Continuous followers in `update`: per-hand swish gain from `h.submerged`, `h.palm.speed`, `h.submergedDepth`; glide rush from `playerCtl.state.speed`; calm drone from `max(ctx.water.calm, ctx.calm) > 0.5`; crackle on nearest 3 of `ctx.lanterns.list` (uses `l.position`, `l.state`, `l.bright`).
### music (`ctx.music`, set at start): `rootMidi, penta, chords, currentChord → {name, root, fifth, intervals, pcs, midi[]}, breathing, scaleNote(degree, octave=4), pitchFor(degree, register=5), isConsonant(midi), nearestConsonant(midi), advance(), raindrop(), breathe(), requestSwell(name, gain=0.35)`. Reacts to `'lanternrelease'` (swell `pad_northern_*`) and `'lotuschord'` (`pad_bioluminescence`); raindrops only when `ctx.energy < 0.15` and no hand submerged.
### ambience: wind/water beds, 5 crickets around `headWorld`, aurora shimmer ∝ `ctx.energy`; `S.startle(min, max)` silences crickets on `'lanternsplash'` (6–12 s), `'lotuschord'` (4–6 s), or a submerged hand with `palm.speed > 1.0`.

## Wave sim (src/world/wavesim.js)
`ctx.water.disturb(x, z, radiusMetres, strength)` queues (≤64) a zero-mean LoG push; per frame ≤16 disturbances total (hand joints and head first). Radius clamped 0.02–0.6 m; height clamped ±0.6. Existing values: hand joints radius `j.radius·2.2+0.03`, strength `speed·0.075·(0.35..1)` ≤0.16; head `(0.28, ≤0.05)`; lotus bloom `(0.18, 0.28)`; lantern release-into-water `(0.14, 0.45)`, dropped lantern landing `(0.12, 0.2)`, held under water `(0.1, 0.08..0.38)` every 0.25 s, floating hull `(0.09, 0.012..0.042)` every 0.5 s within 9 m; drip landing `(0.045, 0.021..0.035)` ≤6/frame. Channels R height, G prev, B afterglow, A energy (plankton/water glow read B,A). `ctx.water.simSnapshot()` → `{ size, maxH, meanGlow, glowFrac, energyFrac, pixels }`.

## Hints (src/world/hints.js)
`HINTS` entries: `{ id, text, after (s since session start), done(ctx, s) → bool, ready(ctx, s) → bool }`; special repeat hints `{ id, text, repeat: true }` (LEAVE, SHOW_HANDS, NO_TRACKING, CONTROLLERS). State `s = { handsSeen, touchedWater ('handenter'), grabbed ('grab'), fireflyLanded, moved, turned, bloomed, sessionStart, shows{} }`. Selection each frame: LEAVE if `ctx.leave.progress > 0.15` (preempts anything), then controllers/no-hands messages, else (if `t > st.cooldownUntil`) the first HINTS entry not learned, not done, `elapsed ≥ after`, shown < 3 times, and `ready`. A non-repeat hint stays until `done` (learned → localStorage `nocturne.hints`, 20 s cooldown) or 14 s (45 s cooldown). Text drawn on a 1024×256 canvas plane 1.05 m ahead at `water.level − 0.015`, additive, ≤1 hint at a time. To add: push an entry into `HINTS` and set its flag from an event.

## Lotus (src/world/lotus.js)
`ctx.lotus = { flowers[6], clusters, pads, open(i), chordCount, nearestBudDistance }`; flower `{ index, note (i%6), position (Vector3, base at level+0.006, bobbing), bud (Vector3, base + 0.045·scale), color, bloom 0..1, open, state 'closed'|'opening'|'open'|'closing', timer, stay 55–75 }`. Touch: any `h.tips[k]` of a `visible` hand within 0.08 m of `f.bud` while `bloom < 0.25 && !open` → `openFlower`: opens over 1.6 s, `ctx.energy += 0.15`, disturb `(0.18,0.28)`, `'lotusbloom'`; closes over 6 s after `stay`. All six open (bloom > 0.6) → `'lotuschord'` once per episode. 4 draw calls (InstancedMesh pads, InstancedMesh flowers with `aBloom`, instanced glow quads + mirror).

## Lanterns (src/world/lanterns.js)
`ctx.lanterns = { list, count, MAX 24, nearestDistance }`; `L = { i, seed, state 'floating'|'held'|'rising', held (hand), incoming, attracted, dropping, position (centre Vector3), top, anchor, bobVel, up, vel, bright 0..1, flame, yaw, wind, riseTime, grab }`; `L.grab = { position: L.position, radius 0.12, active, held, warm: true, kind: 'lantern', lantern: L, onGrab, onRelease }` in `ctx.grabbables`. Held: 8 cm string pendulum under `hand.pinch.point`. Release with bottom above water → `'rising'` (0.25→0.5 m/s, `'lanternrelease'`, regrabbable 3 s, energy bump at 3 m, becomes star at 25 s → `'lanternstar'` then respawns far); else floats + `'lanternsplash'`. Floating lanterns home toward the player while `<3` float within 1 m, are pulled toward an open non-pinching hand within 0.35 m, and shed `'lanternsplash'` on dropped landings. 4 draw calls (bodies InstancedMesh + 3 instanced quad meshes).

## Fireflies (src/world/fireflies.js)
`ctx.fireflies = { count N (300·particleScale), landedCount, positions (Float32Array N·3), brightness, states (Uint8Array: 0 WANDER,1 APPROACH,2 LANDED,3 SCATTER), homes, coherence }`. Three home clouds; per hand 8 landing slots `SLOT_JOINTS`. Recruit when `hs.visible && !hs.submerged && hs.openStill` (one firefly per 0.35–0.65 s, nearest wandering within 14 m, approach ≤0.6 m/s); lands when within 0.025 m and `hs.still || hs.speed < 0.15` → `'fireflyland'`, `ctx.energy += 0.05`, stays 8–18 s; leaves if `hs.speed > 0.35`; `hs.speed > 0.7` scatters everything within 0.6 m. Points + mirror Points (2 draw calls), typed arrays only.
Drips (`ctx.drips = {count, spawned, landed, emitted}`): triggered by `h.leftWater`, 256-slot Points, `'drip'`. Leave: both palms within 0.09 m, normals facing (`fa > 0.45, fb < −0.45, dot < −0.5`), not submerged, no pinch → `ctx.leave.progress` (0..1 over 2.5 s) → `'leave'` + `ctx.xr.end()`.

## Harness
- `npm run harness` = `node tools/harness/run.mjs [--frames 240] [--timeline file.js] [--shots 3,7,11,14] [--out dir] [--no-xr]`: desktop phase (`look`, `setHand`, `setTime`), then `enterXR()`, manual clock (`duration/frames` s per frame), default 15 s timeline, screenshots, `summary.json { ok, errors, warnings, stats:{ready, desktop_*, xr_t*, afterExit}, fakeXR:{frames, events, warnings}, console }`. Fails on pageerror, console.error, shader/WebGL/404 patterns, HTTP ≥400, `stats().errors`.
- `npm run scenario` = `tools/harness/scenario.mjs`: helpers `frame()` (one rAF), `frames(n)`, `stats()`, `world()`, `events()`, `setHand(hs, worldXYZ, pinch, extra)` (subtracts `window.__nocturneCtx.player.position` then `__fakeXR.setHandPose`), `local(hs, rigLocalXYZ, pinch, extra)`, `step(name, ok, info)`; clock `c.mode='manual'; c.step=1/36`. Proof pattern: drive poses, advance frames, assert on `events()` types / `world()` / `stats()` / `window.__nocturneCtx.<module>` fields.
- `window.__fakeXR`: `clock {mode 'auto'|'manual', rate, step, time, set(t), advance, pause, resume}`, `timeline {fn, duration, name}`, `setTimeline(fn(t)→{head,left,right}, duration)`, `setHead([x,y,z], yawDeg, pitchDeg, rollDeg)`, `setHandPose('left'|'right', { position:[x,y,z], yawDeg, pitchDeg, rollDeg, pinch 0..1|bool, curl 0..1, spread 0..1, visible })` (override persists until `clearOverrides()`; missing keys fall back to the timeline/rest pose `{ position: [±0.25, 0.9, −0.3], curl 0.15, spread 0.5, pinch 0 }`), `getState() → { time, frames, head, left/right: { tracked, position, pinch, pinchDistance, wrist, indexTip, thumbTip, lowestJointY } }`, `frames, events [{t,type,hand}], warnings, config`.
- `setHandPose` frame: WebXR `local-floor` reference space = **rig-local** metres, +Y up, −Z forward, floor y=0, head at (0,1.6,0). `position` is the **wrist**; fingers extend ~17 cm along −Z (yaw 0); `palm.position` (middle-finger-metacarpal) ≈ wrist + (∓0.009, 0.002, −0.031). Right-hand local frame: back of hand +Y, palm normal −Y (palm-down at roll 0), thumb −X; left is the X mirror. Rotation order yaw(+Y) → pitch(local +X, positive tilts fingers up; −20 dips them) → roll(local +Z): `rollDeg 180` = palm up; left `rollDeg 90` → palm faces +X; right `rollDeg −90` → palm faces −X. Pinch: `pinch:1` snaps thumb-tip/index-tip together (distance 0 → app pinch after 2 frames; fake `selectstart` at <0.015 m, `select` at >0.03 m), curl on index +0.55·pinch. Open hand: `curl ≤ ~0.1` (default 0.15 is open; curl ≥ ~0.5 fails `open`; `curl 1` ≈ grasp). Visible false = tracking loss.
- World ↔ rig: after calibration (≥12 samples, >1 s; fake head 1.6 m → standing) `player.position.y = 0.95 + 0.60 − 1.6 = −0.05`, so world y = rig-local y − 0.05 and the surface is at rig-local y ≈ 1.00; wrist at local y 0.6 puts all WATER_JOINTS ~40 cm under → `submerged`. Still: hold the same pose ≥0.3 s (`still`), ≥1 s more for `openStill` (scenario: 200 frames at 1/36 s with `rollDeg ±180`, `pinch 0`). Rig moves only via pinch-and-pull, so pass world coords through `setHand` (re-subtracts rig each call).
- `window.__nocturne = { ready (Promise), enterXR(), exitXR(), look(yawDeg, pitchDeg), setHand({x,y,pinch,submerged}) (desktop mouse hand, 0..1 screen coords), setTime(s) (emits 'timejump'), simSnapshot(), audioStats() → {rms, peak, rmsDb, peakDb}, events() → eventLog copy, world() → { lanterns:[{x,y,z,state}], lotus:[{x,y,z,bloom,open}], rig:{x,y,z,ry}, head:[x,y,z] }, stats() → { frame, t, fps, drawCalls, triangles, points, programs, geometries, textures, xr, mode, energy, errors[], hands:{left, right (visible), pinchL, pinchR, submergedR, debug}, calibrated, seated, calm, moonAltitudeDeg, lanternStars, aurora, lanterns, fireflies, fireflyLanded, lotusOpen, player:{x,y,z}, water (level) }, ctx }`; `window.__nocturneCtx === ctx` (read any `ctx.<module>` field directly, e.g. `ctx.hands.right.stillFor`, `ctx.leave.progress`). A new feature should expose a small `ctx.<name>` object with counters/state and, if useful, add fields to `stats()`/`world()` in main.js.
